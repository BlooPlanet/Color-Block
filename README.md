# Phantom Block
basic voxel engine where you can place and break blocks.
 <img width="1701" height="1005" alt="Screenshot 2026-11-07 at 18 59 25" src="https://github.com/user-attachments/assets/28a83b68-ffd6-4d42-8d2b-0003d3535b05" />
try demo:
Controls: (wasd to move),(double jump to toggle fly mode), (mouse click to place/break phantom block)

Local Setup Instruction: first step download project source code and then open downloaded folder with unity project.
Note:you need unity 2021.3 game engine.
